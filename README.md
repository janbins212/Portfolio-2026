# John Benzh P. Cuy Portfolio

A responsive React + TypeScript portfolio for an IT graduate specializing in Database Systems.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then preview it with `npm run preview`.

## Deploy to GitHub Pages

The site is published at <https://janbins212.github.io/Portfolio-2026/>. Every push to
`main` runs the GitHub Actions workflow in `.github/workflows/deploy.yml` and deploys
the production build to GitHub Pages.
